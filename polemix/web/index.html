    What should we argue about?

    Write a motion, choose who argues it, and start the debate. The debaters take turns over several rounds, then a moderator sums up where they agree and where they don't.

    The debaters are played by a model running on your own computer. Nothing is sent anywhere else.

    Model connection

    This page is served by the Polemix app on your computer, which connects to . To change the server, restart it with --base-url.

    Connecting from this website

    LM Studio: in the Developer tab, turn on Enable CORS, load a model and start the server.

    Ollama: quit Ollama, run launchctl setenv OLLAMA_ORIGINS "*" (Mac) or set the OLLAMA_ORIGINS variable to * (Windows), then reopen it.

    Use Chrome, Edge or Firefox, and allow access to your local network if the browser asks. On a phone, use demo mode.
